# Граница медиа-воркера

[English version](media-worker-architecture.md)

`app.processing.media.worker` запускается `app.collector.service` как asyncio-задача и получает существующий аутентифицированный `TelegramClient` коллектора. Это сделано намеренно: отдельный процесс Telethon с тем же session-файлом может повредить состояние сессии или вызвать проблемы с авторизацией Telegram.

`ALPR_WORKER_COUNT=1` — единственное поддерживаемое безопасное значение по умолчанию. Воркеры используют один лениво создаваемый глобальный экземпляр FastALPR, поэтому параллельный inference отключён до подтверждения потокобезопасности.

Будущее разделение сначала должно ввести границу получения Telegram-медиа. Fetcher может использовать сессию и сохранять локальный входной файл; отдельный локальный обработчик изображений затем сможет выполнять JPEG-оптимизацию и ALPR без Telethon. Только после этого разделения обработка изображений может стать независимым сервисом.
