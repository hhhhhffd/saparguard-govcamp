# Стек фронтенда

[English version](frontend-stack.md)

SaparGuard рендерит страницы и HTML-фрагменты на сервере с Jinja2. HTMX 2.x, Alpine CSP и Tailwind CSS 4.x устанавливаются через pnpm и копируются или собираются в `app/web/static`; production не загружает фронтенд-код с CDN и не запускает Node-сервер.

Одобренные будущие зависимости, которые намеренно пока не установлены:

- ECharts — добавлять только вместе с первой работающей диаграммой;
- Cytoscape.js — добавлять только вместе с первым работающим графом связей;
- MapLibre GL JS — добавлять только вместе с первой работающей картой.
